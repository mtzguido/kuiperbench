KernelBench L1 #84 — Depthwise 2D Convolution (asymmetric input, square kernel)
================================================================================

Reference (from KernelBench/level1/84_conv_depthwise_2D_asymmetric_input_square_kernel.py):

    nn.Conv2d(in_channels=128, out_channels=128,
              kernel_size=(3, 3), stride=1, padding=0,
              groups=128, bias=False)

    input  : (B=64, 128, 256, 512)
    output : (64, 128, 254, 510)
        H_out = (256 + 0 - 3)/1 + 1 = 254
        W_out = (512 + 0 - 3)/1 + 1 = 510

Reduction depth per output pixel: 3 * 3 = 9 muls/adds.
Total fmadds: 64 * 128 * 254 * 510 * 9 ≈ 9.5e9 (~9.5 GFLOPs).

`out_channels=128, in_channels=128, groups=128` → channel-multiplier 1
(vanilla depthwise — same regime as #82 / #83 / #85).  Asymmetric
input (256×512) is a no-op for the spec; H_in ≠ W_in is allowed
naturally.
