L1 #93 masked_cumsum — Skeptic review
=====================================

PyTorch semantics: `torch.cumsum(x * mask, dim=1)` for a bool mask.

`Kuiper.KB.MaskedCumSum.masked_cumsum_fw_f32` verifies the complete
operation. It allocates an f32 GPU scratch tensor, uses the verified map
kernel to gate each input with the corresponding bool-storage byte, runs the
verified row-block scan over the gated rows, and frees the scratch. Its direct
postcondition states that output `(r,i)` approximates the real prefix sum of
`if mask[r,j] != 0 then to_real(input[r,j]) else 0`.

There are no new admits, assumptions, or magic. The Python wrapper has no
fallback. The entry point allocates and returns its owned GPU result. The
bridge enforces same-device contiguous CUDA f32 and `torch.bool` inputs, treats
the mask's one-byte storage as the verified u8 ABI, checks scan/map bounds,
selects the input device, makes one extracted call, and wraps the pointer with
a `cudaFree` deleter. It performs no copy, output allocation, mask conversion,
multiplication, selection, or scan itself.
