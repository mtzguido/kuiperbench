RMSNorm skeptic notes (post spec strengthening)
================================================

(a) Math correspondence
-----------------------
The (B*HW, C) chest2 view of `l2_bcm_pages B HW C` has imap
    (r, ci) ↦ (r/HW)*C*HW + ci*HW + (r%HW)
which is exactly the row-major (B,C,H,W) byte offset for
b=r/HW, hw=r%HW, c=ci.  So spec rows are spatial positions, columns channels: `rmsnorm_post` genuinely pins per
(b,h,w) RMS normalisation along the channel axis.  The verified entry
point computes 1/C itself and proves that it approximates the real
reciprocal.  The public post directly relates every output cell to
the real RMS normalization; no floating statistic escapes existentially.

(b) Proof is genuine
--------------------
The .fst chains three verified primitives:
  reduce_batched sq_step → seq_reduce_rows sq_step sx
  map_gpu inv_rms_fn     → lseq_map (inv_rms_fn …) …
  row_scale              → s_row_scale … sx
The only non-trivial step is `row_reduce_partial_sq_approx`
(Kuiper.Spec.RMSNorm.fst), which inducts on `row_reduce_partial`
to re-express it as `seq_fold_left add zero (seq_map sq_step
row)` and discharges the approx via `sum_is_approx`.  There is no local
`admit` or `magic`; the proof uses the documented temporary
`rsqrt_approx` compatibility assumption pending its upstream Kuiper law.

(c) Edge cases
--------------
Zero row: sumsq=0, inv=rsqrt(eps); the direct real contract requires
positive real epsilon.  C=0 and HW=0 are ruled out by the kernel
preconditions.  Array2 `is_global` admission is unchanged.
