SKEPTIC — KernelBench L1 #45 AvgPool2D
======================================

The canonical input contains exactly 2^32 f32 elements, while Kuiper SizeT
arrays are restricted to fewer than 2^32 elements.  The public extracted
[avgpool2d_full_alloc_f32] therefore accepts two disjoint pointers to the
checked 2^31-element halves.  Its single postcondition describes the logical
concatenation of those halves; the split is solely an ABI representation
boundary and does not split the functional specification.

Inside that one entry, each half is processed through the complete W/H
count-include-pad pipeline: WindowReduce1D sum, verified reciprocal scale,
proved zero-copy BCM layout recast, second WindowReduce1D sum, and verified
scale.  A verified pointwise concat kernel then writes both complete half
results into one final allocation in canonical (B,C,H_out,W_out) byte order.
The post is input-linked and exact at f32, with no associativity or numerical
error claim.

The C++ entrypoint only checks the fixed KernelBench shape and pooling
parameters, selects the CUDA device, computes the fixed second-half pointer,
calls the extracted entry once, and wraps its returned pointer.  It performs
no pool pass, transpose, view transformation, allocation, scaling, chunking,
or multi-kernel orchestration.

The relation between the original allocation and that computed second-half
pointer is an accepted representation boundary for the current solution.

No challenge-local admit, assume, magic, or trusted copy primitive is added.
