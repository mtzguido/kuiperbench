KernelBench L1 #85 — Depthwise 2D Convolution (asymmetric input, asymmetric kernel)
====================================================================================

Reference (from KernelBench/level1/85_conv_depthwise_2D_asymmetric_input_asymmetric_kernel.py):

    nn.Conv2d(in_channels=128, out_channels=128,
              kernel_size=(3, 7),
              stride=(1, 1), padding=(0, 0),
              dilation=(1, 1), groups=128, bias=False)

    input  : (B=32, 128, 128, 256)
    output : (32, 128, 126, 250)
        H_out = (128 + 0 - 3)/1 + 1 = 126
        W_out = (256 + 0 - 7)/1 + 1 = 250

Reduction depth per output pixel: 3 * 7 = 21 muls/adds.
Total fmadds: 32 * 128 * 126 * 250 * 21 ≈ 2.7e9 (~2.7 GFLOPs).

The "everything-asymmetric" depthwise: K=(3,7), asymmetric input,
per-axis stride / pad / dilation.  Spec already handles this fully
generally — K_h, K_w, S_h, S_w, P_h, P_w, D_h, D_w are all
independent parameters.
