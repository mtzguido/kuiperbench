STATUS — KernelBench L1 #72
===========================

ConvTranspose3D — asymmetric, strided/padded/grouped
PASS — one complete Kuiper-verified grouped operation with a full-output
functional postcondition.

Verified surface
----------------
  - Kuiper.Spec.ConvTranspose3D defines the grouped operation over the
    original NCDHW input and PyTorch ConvTranspose weight layout.
  - Kuiper.Kernel.ConvT3D.GroupedNaive computes the complete groups=4 output

    range are derived inside the verified kernel; there are no host slices.
  - Kuiper.KB.ConvT3DGrouped72 allocates and initializes the implicit zero
    bias, allocates the complete output, launches the grouped kernel, frees
    the temporary bias, and returns the output behind one public entry point.
  - The C++ bridge only checks the fixed #72 configuration, calls that entry
    once, and wraps the returned device pointer as a tensor.

The checked configuration is B=8, Cin=Cout=32, groups=4, input
12x24x48, kernel 3x5x7, stride 2x2x2, padding 1x2x3,
output_padding 1x1x1, dilation 1x1x1, and bias=False.  Its output is
8x32x24x48x96.

No new admits, assumptions, magic, or unverified layout/composition code were
introduced.
