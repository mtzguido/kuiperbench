STATUS — KernelBench L1 #41 MaxPool1D
=====================================

Phase 0 (functional spec) landed.  GPU kernel impl deferred.

Landed (verified, ADMIT=0):

  - src/lib/spec/Kuiper.Spec.Pool1D.{fst,fsti}
    Scalar-polymorphic functional spec for 1-D windowed pooling
    (max + avg, kernel/stride/padding/dilation).  Max-pool spec
    is exact (`fmax`-fold equality); avg-pool spec is approximate
    (`%~` post over `Kuiper.Real`-valued window sum).  See the
    module preamble for the full design rationale.

NOT landed:

  - The `Kuiper.Kernel.WindowReduce1D` Pulse primitive that the
    kernel impl would use.  This is the long pole — the per-thread
    permission split for K-element overlapping reads (#41 has
    K=8, S=1, so each input element is read by up to 8 output
    threads) requires non-trivial `forevery_factor'` plumbing
    that doesn't reduce to any existing primitive.  Estimated
    ~1000 LOC of new Pulse kernel + proof.

  - `Kuiper.KB.MaxPool1D` (~150 LOC, mechanical once the primitive
    is in place).

  - The Python harness, bridge, and `run.sh` — deliberately not
    stubbed because the kernel they would call doesn't exist
    yet.  Adding them now would just be skeptic-bait.
