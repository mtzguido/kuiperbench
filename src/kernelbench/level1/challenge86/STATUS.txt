KernelBench L1 #86 — Depthwise-Separable 2D Convolution
========================================================

Reference (from KernelBench/level1/86_conv_depthwise_separable_2D.py):

    self.depthwise = nn.Conv2d(in_channels=64, out_channels=64,
                               kernel_size=3, stride=1, padding=1,
                               dilation=1, groups=64, bias=False)
    self.pointwise = nn.Conv2d(in_channels=64, out_channels=128,
                               kernel_size=1, bias=False)

    input  : (B=16, 64, 512, 512)
    after dw : (16, 64, 512, 512)        ← P=1 preserves spatial
    output : (16, 128, 512, 512)         ← pw 1×1 preserves spatial

Reduction depth per output pixel: 3*3 (dw) + 64*1 (pw) = 9 + 64 = 73 fmadds.
Total fmadds: 16 * 64 * 512 * 512 * 9   (depthwise stage)
            + 16 * 128 * 512 * 512 * 64 (pointwise stage)
            ≈ 2.5e9 + 2.1e10 = 2.4e10 (~24 GFLOPs).
