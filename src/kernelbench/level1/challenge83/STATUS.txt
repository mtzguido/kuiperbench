KernelBench L1 #83 — Depthwise 2D Convolution (square input, asymmetric kernel)
================================================================================

Reference (from KernelBench/level1/83_conv_depthwise_2D_square_input_asymmetric_kernel.py):

    nn.Conv2d(in_channels=8, out_channels=8,
              kernel_size=(3, 1), stride=1, padding=0,
              dilation=1, groups=8, bias=False)

    input  : (B=64, 8, 512, 512)
    output : (64, 8, 510, 512)
        H_out = (512 + 0 - 3)/1 + 1 = 510
        W_out = (512 + 0 - 1)/1 + 1 = 512

Reduction depth per output pixel: 3 * 1 = 3 muls/adds.
Total fmadds: 64 * 8 * 510 * 512 * 3 ≈ 4.0e8 (~0.4 GFLOPs).

Asymmetric kernel (3×1) — exercises K_h ≠ K_w but everything else
matches #82.  PyTorch passes `kernel_size=(3, 1)` directly to Conv2d.
