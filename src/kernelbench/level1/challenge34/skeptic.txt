Skeptic review — KB MeanVarNorm (#34, #35) functional spec
===========================================================

Spec faithfulness
-----------------
The verified entry point establishes a direct real-valued contract.  For
every row, [mean_var_post] relates the concrete output via [%~] to

  mean = (1/D) Σ x[j]
  var  = (1/D) Σ x[j]^2 - mean^2
  y[j] = (x[j] - mean) / sqrt(var + eps).

There are no numerical existentials in the public row or tensor
postcondition.  The sum, second moment, variance, reciprocal square root,
and affine bias used by the float implementation remain proof-local.  The
entry point computes 1/D itself and proves that it approximates the real
reciprocal; it is not an unchecked caller argument.

The public precondition [mean_var_domain] requires each real
[var + eps] to be positive.  This is the exact domain on which the temporary
[Kuiper.KB.Compat.RsqrtApprox.rsqrt_approx] assumption connects floating
[rsqrt] to [FStar.Math.Sqrt.rsqrt].  That compatibility law is proposed for
upstream Kuiper and is the numerical proof's explicit local trust debt.

Proof shape
-----------
Each row is copied into scratch.  Two verified reductions establish
approximations to the real sum and sum of squares.  The scalar approximation
laws then derive the real mean, second moment, variance, reciprocal square
root, and output affine expression.  A pointwise proof closes the direct
real row postcondition, while the host loop preserves completed rows and the
unmodified suffix.

For #35 (GroupNorm), the bridge views every group as one row and calls the
same extracted #34 entry point.  Its C ABI remains `(rows, row_size, eps, x)`;
the domain and postcondition are erased proof obligations and add no runtime
argument.

Edge cases
----------
- The exported [b] and [d] are positive by [szp].
- A constant row with positive eps is in-domain and normalizes to real zero.
- A row with non-positive real [var + eps] is deliberately outside the
  theorem's domain; the old claim about accepting rsqrt(0) was not justified
  by the available approximation law.
