Per-challenge dimensions
------------------------

From `KernelBench/KernelBench/level1/79_conv_transposed_1D_asymmetric_input_square_kernel___padded____strided____dilated__.py`:

  batch_size = 16, in_channels = 32, out_channels = 64
  spatial input = 131072
  kernel = 3
  stride = 2
  padding = 1
  dilation = 2
  output_padding = 0
  groups = 1
  bias = False

Notes: 1-D ConvTranspose with stride+padding+dilation.

Output spatial dims via the standard PyTorch formula
  L_out = (L_in - 1)*S - 2*P + D*(K - 1) + OPad + 1   (per axis)
computed by the bridge via the VERIFIED extracted helper
[convt_out_dim] (Kuiper.KB.ConvT2DGeneral / ConvT3DGeneral), whose
[ensures] equals the formula above per axis — there is no hand-rolled
C++ output-size arithmetic.  The output buffer itself is allocated
INSIDE the verified self-allocating entry [convt*_general_alloc_f32]
and returned to the bridge via from_blob (no torch::empty).
